# Анализ данных HeadHunter

## О проекте

Учебный проект по анализу данных резюме соискателей с платформы HeadHunter.

В рамках проекта выполнены:
- предварительная обработка и очистка данных;
- исследование распределения признаков;
- анализ зависимостей между признаками;
- исследование заработной платы соискателей;
- визуализация результатов с помощью интерактивных графиков.

## Данные

- `hh_test.csv` — исходный датасет с резюме соискателей ([скачать с Google Drive](https://drive.google.com/file/d/15fGQii4hKAgDWftnqd8nJOhXjIVyzQhA/view?usp=sharing)).
- `ExchangeRates.csv` — таблица курсов валют, используемая для перевода заработной платы в рубли.

## Структура проекта

- `FirsanovaPP.ipynb` — основной Jupyter Notebook с анализом данных.
- `graphs/` — интерактивные графики в формате HTML.
- `ExchangeRates.csv` — данные о курсах валют.
- `README.md` — описание проекта.
