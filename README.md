# Анализ данных HeadHunter

## О проекте

Учебный проект по анализу данных резюме соискателей с платформы HeadHunter.

В проекте выполнены:
- предварительная обработка данных;
- исследование распределения признаков;
- анализ зависимостей между признаками;
- визуализация результатов.

## Данные

- `hh_test.csv` — исходный датасет. [Скачать с Google Drive](https://drive.google.com/file/d/15fGQii4hKAgDWftnqd8nJOhXjIVyzQhA/view?usp=sharing).
- `ExchangeRates.csv` — таблица курсов валют, используемая для перевода зарплат в рубли.

## Структура проекта

- `FirsanovaPP.ipynb` — основной ноутбук с анализом данных.
- `graphs/` — интерактивные графики в формате HTML.
- `ExchangeRates.csv` — данные о курсах валют.
